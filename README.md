# 🎈 IT: Welcome to Derry

> *"We all float down here."*

## About the Series
**IT: Welcome to Derry** is an American horror series on **HBO**. It is a prequel to the *IT* films, based on Stephen King's novel *It*. The story is set in **Derry, Maine** in the 1960s, and it explores the dark history behind the town and the evil that keeps coming back.
